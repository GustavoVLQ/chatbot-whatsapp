# Chatbot WhatsApp - Assistente Virtual

Este projeto implementa um chatbot para WhatsApp utilizando a biblioteca `whatsapp-web.js`. O chatbot é um assistente virtual que oferece informações sobre planos de serviços, como funciona o atendimento, valores, benefícios, como aderir, entre outros.

## Pré-requisitos

- [Node.js](https://nodejs.org/) instalado.
- [npm](https://www.npmjs.com/) (gerenciador de pacotes do Node.js).
- Uma conta do WhatsApp para realizar a integração via WhatsApp Web.

## Instalação

### Passo 1: Clone o repositório

Clone o repositório para sua máquina local:

```bash
git clone https://github.com/GustavoVLQ/chatbot-whatsapp.git
```
### Passo 2: Instale as dependências

Instale as dependências do projeto:

```bash
npm install
```
### Passo 3: Inicie o programa

Inicie o ChatBot e conecte no seu whatsapp

```bash
node chatbot.js
```
